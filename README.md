# Flying Grid — Dark Premium EV Tech

Responsive single-page landing website for Flying Grid's electric two-wheeler charging station partnership program. It uses a dark green/black theme, neon green accents, EV photography, and premium typography.

## Files
- `index.html` — complete website, including HTML, CSS and JavaScript
- `logo.png` — the original Flying Grid logo supplied for this website

## Preview locally
Keep `index.html` and `logo.png` in the same folder and open `index.html` in a modern browser. An internet connection is needed for remote photos and Google Fonts.

## Publish with GitHub Pages
1. Create a GitHub repository, for example `flying-grid-website`.
2. Upload `index.html`, `README.md`, and `logo.png` to the repository root.
3. Open **Settings → Pages**.
4. Select **Deploy from a branch** under Build and deployment.
5. Choose branch `main` and folder `/(root)`, then click **Save**.
6. Wait for deployment. The public website URL will appear in the Pages settings.
